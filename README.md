# «Школа»: расписание, ДЗ и напоминания на iPhone

Простое приложение на Swift и SwiftUI. Все данные хранятся на телефоне: без интернета, сервера и регистрации.

## Что умеет

| Вкладка | Что там |
|---|---|
| **Сегодня** | Уроки на сегодня и на следующий учебный день вместе с ДЗ. Нажмите на урок, чтобы записать ДЗ. |
| **Расписание** | Нажмите на день и впишите предметы по порядку. Ниже — кружки и секции. |
| **ДЗ** | Все записанные задания по дням. Кнопка «+» добавляет новое задание. Когда день урока прошёл, ДЗ удаляется само. |
| **Настройки** | Время уведомлений, тест, дата продления, резервная копия. |

**Уведомления:**
- **7:00:** уроки на сегодня и кружки;
- **17:30:** расписание на завтра и ДЗ на завтра.

Время можно поменять в «Настройках».

iOS показывает свёрнутое уведомление в 4–5 строк. Чтобы увидеть его полностью, нажмите на уведомление и подержите (или потяните его вниз). Если просто нажать, откроется вкладка «Сегодня», где всё расписано целиком.

## Как это устроено

```
Код на GitHub  →  GitHub сам собирает приложение на облачном Mac  →  файл SchoolHelper.ipa
               →  программа Sideloadly на Windows ставит его на iPhone по кабелю
```

Свой Mac и Xcode не нужны.

## Установка (один раз)

### Шаг 1. Получить файл приложения с GitHub

1. Зарегистрируйтесь на **github.com**, это бесплатно.
2. Создайте репозиторий: кнопка **+** вверху справа → **New repository**.
   - Имя: `SchoolHelper`.
   - **Private** или **Public**: в коде нет ничего личного, ваши расписание и ДЗ хранятся только на телефоне.
   - Галочки README и .gitignore **не ставьте**.
   - Нажмите **Create repository**.
3. Загрузите код одним из двух способов:
   - **Проще всего:** пришлите Claude ссылку на репозиторий, он загрузит код сам. Может появиться окно входа в GitHub — войдите.
   - **Вручную:** на странице пустого репозитория нажмите ссылку **uploading an existing file**. Перетащите в окно браузера всё содержимое папки `D:\Claude\SchoolHelper`, включая папку `.github`, и нажмите **Commit changes**.
4. Подождите 5–10 минут: GitHub соберёт приложение. Ход сборки виден на вкладке **Actions**: жёлтый кружок — идёт сборка, зелёная галочка — готово.
5. На главной странице репозитория справа найдите **Releases** → **Сборка 1** и скачайте файл **SchoolHelper.ipa**. Сохраните его, он понадобится для продления.

Если в **Actions** стоит красный крестик, откройте эту сборку, скопируйте текст ошибок (они вверху, в блоке **Annotations**) и пришлите Claude.

### Шаг 2. Установить на iPhone через Sideloadly

1. Скачайте **Sideloadly** для Windows с сайта **sideloadly.io** и установите.
2. Если Sideloadly попросит **iTunes** или **iCloud**, скачайте их **с сайта apple.com**, а не из Microsoft Store.
3. Подключите iPhone кабелем, разблокируйте его и на вопрос «Доверять этому компьютеру?» ответьте **Доверять**.
4. В Sideloadly:
   - перетащите файл `SchoolHelper.ipa` в окно;
   - в поле **Apple account** впишите свой Apple ID (почту);
   - нажмите **Start**, введите пароль и код подтверждения, если попросит.
   
   Пароль Apple ID вводится в стороннюю программу. Если вам это не нравится, заведите отдельный Apple ID только для этого.
5. На iPhone:
   - **Настройки → Конфиденциальность и безопасность → Режим разработчика** → включить. Телефон перезагрузится, нажмите **Включить**.
   - **Настройки → Основные → VPN и управление устройством** → ваш Apple ID → **Доверять**.
6. Откройте приложение **«Школа»** и разрешите уведомления.

### Шаг 3. Заполнить и проверить

1. **Расписание** → нажмите на **Понедельник** → впишите предметы по порядку → **Сохранить**. Так же для остальных дней. Кнопка ☰ справа от строки подставляет уже введённый предмет.
2. Кружки и секции добавляются там же, ниже.
3. **Настройки** → **Тест: утреннее уведомление** → заблокируйте телефон. Через 5 секунд придёт уведомление.

## ⚠️ Каждые 7 дней: продление

С бесплатным Apple ID приложение работает 7 дней, потом перестаёт открываться. Продление занимает пару минут:

1. Подключите iPhone к компьютеру.
2. Откройте Sideloadly, перетащите **тот же** файл `SchoolHelper.ipa` и нажмите **Start**.

**Расписание и ДЗ при этом сохраняются.**

Приложение само напомнит о продлении:
- накануне в 19:00 придёт уведомление;
- за 2 дня на вкладке «Сегодня» появится красное предупреждение;
- точная дата всегда видна в «Настройки → Продление».

Если забыли продлить, ничего страшного: после продления всё будет на месте.

В Sideloadly есть автоматическое продление по Wi-Fi (Auto-refresh). Если получится его включить, кабель подключать не придётся, но компьютер должен быть включён и находиться в той же Wi-Fi-сети.

**Не удаляйте приложение с телефона**, иначе данные пропадут. На всякий случай иногда делайте копию: **Настройки → Сохранить копию данных** (например, в «Файлы» или себе в мессенджер). Восстановить можно там же.

## Как поменять что-то в приложении

Напишите Claude, что изменить. Он поправит код и отправит его на GitHub, а через 5–10 минут в **Releases** появится новая сборка. Установите её через Sideloadly поверх старой, данные сохранятся.

## Если что-то не так

| Проблема | Что сделать |
|---|---|
| На вкладке **Actions** пусто после ручной загрузки | Не загрузилась папка `.github`. В репозитории нажмите **Add file → Create new file**, в имя впишите `.github/workflows/build.yml`, вставьте содержимое этого файла и нажмите **Commit changes** |
| Сборка с красным крестиком | Пришлите Claude текст из блока **Annotations** на странице сборки |
| Sideloadly пишет, что Bundle ID недоступен | Скажите Claude, он поменяет идентификатор приложения |
| Приложение не открывается, «Ненадёжный разработчик» | «Настройки → Основные → VPN и управление устройством» → **Доверять** |
| Приложение перестало открываться | Прошло 7 дней, продлите через Sideloadly (см. выше) |
| Уведомления не приходят | 1) «Настройки iPhone → Уведомления → Школа»: уведомления разрешены? 2) Во вкладке «Настройки» приложения счётчик «Запланировано уведомлений» больше 0? 3) Расписание заполнено? Дни без уроков пропускаются, если не включено «Уведомлять в дни без уроков». 4) Если утром включён фокус «Сон», уведомление в 7:00 может быть скрыто. |
